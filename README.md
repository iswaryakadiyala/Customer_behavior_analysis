# 🛍️ Customer Shopping Behavior Analysis

## 📌 Overview
This project analyzes customer shopping behavior to uncover patterns in purchasing habits, spending trends, subscription preferences, product performance, and customer segmentation.

The project follows a complete end-to-end data analytics workflow:

- Data loading and preprocessing in Python
- Exploratory Data Analysis (EDA)
- Data cleaning and feature engineering
- SQL analysis using PostgreSQL
- Interactive dashboard creation in Tableau

This project demonstrates practical data analytics skills used in real-world business environments to generate actionable insights and support data-driven decision-making.

---

## 📂 Dataset Information

- **Dataset Name:** Customer Shopping Behavior Dataset
- **Format:** CSV
- **Number of Records:** 3,900
- **Number of Features:** 18

### Key Columns

- Customer ID
- Age
- Gender
- Item Purchased
- Category
- Purchase Amount (USD)
- Location
- Size
- Color
- Season
- Review Rating
- Subscription Status
- Shipping Type
- Discount Applied
- Promo Code Used
- Previous Purchases
- Payment Method
- Frequency of Purchases

### Project Objective
The primary objective of this project is to analyze customer demographics and purchasing behavior to identify:

- High-value customer segments
- Top-performing product categories
- Spending patterns across age and gender groups
- Impact of subscriptions and discounts on revenue
- Opportunities to improve customer retention and sales
